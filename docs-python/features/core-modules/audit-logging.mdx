The Audit Logging module provides a structured way to emit audit log events to the [SAP Audit Log Service](https://help.sap.com/docs/audit-log-service).
Both the standard and the next-generation (NG) audit log APIs are supported.

### Data Access Events

```python
from sap_cloud_sdk.audit_log import AuditLogger

logger = AuditLogger()
logger.log_data_access(
    object_type="BusinessPartner",
    object_id="1000001",
    attributes=["Name", "Address"]
)
```

### Data Modification Events

```python
logger.log_data_modification(
    object_type="SalesOrder",
    object_id="SO-4500012345",
    attributes=[{"name": "Status", "old_value": "Open", "new_value": "Closed"}]
)
```
